## 💡 问题和建议

### 问题1: 初期急速降级

**建议**:
1. 提高初始带宽估计
   ```cpp
   start_bitrate_bps: 300000 -> 1500000  // 提升到1.5 Mbps
   ```

2. 调整Quality Scaler阈值
   ```cpp
   ScalingSettings { low = 15, high = 25 }  // 放宽阈值
   ```

3. 禁用初期Quality Scaler（前30秒）

### 问题2: 分辨率分布过于分散

**建议**:
1. 设置最低分辨率限制
   ```cpp
   min_resolution = 640x360  // 不低于360p
   ```

2. 增加分辨率切换延迟
   ```cpp
   scaling_delay_ms = 5000  // 5秒后才允许降级
   ```

### 问题3: VP9编码性能

**建议**:
1. 使用硬件VP9编码器（如果可用）
2. 降低VP9编码质量设置以提高速度
3. 考虑使用H.264（更稳定）
