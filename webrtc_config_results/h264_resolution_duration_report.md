## 📝 建议

### 提高1080p稳定性

1. **调整Quality Scaler阈值**
   ```cpp
   // 当前可能的阈值
   ScalingSettings { low = 24, high = 37 }

   // 建议调整为
   ScalingSettings { low = 15, high = 25 }
   ```

2. **增加初始带宽估计**
   ```cpp
   start_bitrate_bps: 500000 -> 1000000  // 从500kbps提升到1Mbps
   ```

3. **禁用Quality Scaler（测试用）**
   ```cpp
   is_quality_scaling_allowed: 0  // 禁用自适应分辨率
   ```

### 添加编码延迟日志

在 `h264_encoder_impl.cc` 的 `Encode()` 函数中添加：

```cpp
#include "rtc_base/time_utils.h"

int32_t H264EncoderImpl::Encode(...) {
  int64_t start_time_us = rtc::TimeMicros();

  // ... 现有编码代码 ...

  int64_t encode_time_us = rtc::TimeMicros() - start_time_us;
  double encode_time_ms = encode_time_us / 1000.0;

  RTC_LOG(LS_INFO) << "H264 encode time: " << encode_time_ms
                   << "ms, resolution: " << width << "x" << height;

  return result;
}
```

这样下次测试就能获得准确的编码延迟数据。
